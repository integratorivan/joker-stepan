# StepanFactory — первый продуктовый бриф

StepanFactory — десктопный harness для разработки с агентами. Из одного приложения пользователь сможет запускать нативные Codex, Claude Code и другие инструменты, вести несколько сессий по одному проекту и проверять результат каждой. Ориентир для интеграции с агентами — [T3 Code](https://github.com/pingdotgg/t3code).

## Навигация

В боковой панели у каждой страницы будет свой маршрут. Порядок сверху вниз:

1. Дашборд
2. Задачи
3. Документы
4. Память
5. Скиллы
6. Чем пользуюсь
7. Настройки

Под страницами будет список сессий, сгруппированных по проектам. Отсюда можно вернуться в существующую сессию или создать новую в выбранном проекте. Для каждой новой сессии приложение создаст отдельный Git worktree, чтобы над одним репозиторием можно было работать параллельно.

## Дашборд

Дашборд даст обзор работы по всем проектам. Здесь пользователь увидит список сессий, чем сейчас заняты агенты и какие вопросы ждут ответа. Из вопроса или активной сессии можно будет перейти прямо к разговору.

## Сессия

Внутри сессии будут две вкладки — «Чат» и «Изменения».

### Чат

Пользователь выбирает модель и ведёт диалог с агентом. Пока агент работает, следующее сообщение можно поставить в очередь. К сообщениям можно прикреплять скриншоты и диаграммы. Чат отображает их прямо в переписке, чтобы детали можно было обсуждать на месте. Ориентир для подачи диаграмм — скилл `pr-before-after`.

### Изменения

Вкладка покажет, как изменилась кодовая база с начала сессии. Пользователь увидит список затронутых файлов и diff каждого файла. Если правка меняет ход выполнения, его можно показать на диаграммах до и после. Для изменений интерфейса можно приложить пару скриншотов одного экрана и рядом увидеть, как он выглядел до правки и как выглядит теперь.
