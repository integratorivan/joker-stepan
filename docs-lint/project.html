Функция и её типы

Маршруту достаточно одной строки. Чистая функция лежит в *.domain.ts, и рядом с ней обязателен тест. Контракт сессии общий для модели, хранилища и представления. Все три импортируют его через import type.

Компонент списка

Тип входных данных лежит рядом с компонентом. Обёртка reatomComponent подписывает представление на чтения ресурса. Каждая ветка сразу возвращает свой JSX.

Запрос и повторная попытка

Рабочее пространство сейчас хранит сессии в sessionStorage. Ниже показан проверяемый пример для HTTP-списка. Его контракт содержит три поля для отображения.

API принимает сигнал отмены, читает ответ как unknown и проверяет каждую строку. Повторную попытку запускает кнопка списка через ресурс.

Модель передаёт сигнал в запрос. Расширение withAsyncData предоставляет компоненту данные, статус и повторную загрузку.

При сборке зависимостей связываем конкретный адрес с API и передаём получившуюся модель в SessionList.

Node.js в Electron

Главный процесс вычисляет путь к ресурсам через node:path и создаёт окно. В режиме разработки он открывает адрес Vite, в сборке загружает локальный HTML.

Что можно взять из iv3

В соседнем репозитории iv3, в Rust-модуле crates/stepan_verify_core/src/sessions.rs, уже есть scan_all(max_age). Он читает локальные индексы Codex и Claude, отбирает недавние сессии и сортирует их по времени обновления.

Это кандидат на повторное использование. Для подключения понадобится граница между Rust и главным процессом Electron, например небольшой CLI с JSON-ответом. В renderer достаточно передавать поля для списка. Сейчас приложение использует браузерное хранилище, интеграция с Rust остаётся отдельной задачей.

Как проверить изменения

npm run lint
Проверяет приложение, инструменты и разрешённые примеры. Правила project/const-functions и project/separate-types отвечают за форму функций и размещение типов. project/file-roles проверяет роль файла по суффиксу и направление импортов между ролями.
npm test
Запускает vitest для чистых функций из *.domain.ts.
npm run docs-lint
Проверяет разрешённые примеры, ожидаемые диагностики и фрагменты исходников на этой странице.
npm run build
Запускает TypeScript, Oxlint, тесты, проверку примеров и производственную сборку Electron.
