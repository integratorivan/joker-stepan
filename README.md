# StepanFactory

<img src="resources/icon.png" alt="Логотип StepanFactory — двое лесорубов пилят бревно" width="160">

Десктопное приложение на Electron, React и TypeScript. Каркас рабочего пространства использует Reatom, компоненты Base UI и Tailwind CSS для раскладки.

## Запуск

Нужен Node.js 24.15 или новее. В корне проекта выполните:

```sh
npm ci
npm run dev
```

Для запуска локальной production-сборки выполните `npm run build`, затем `npm start`. Сборка кладёт приложение в `out/`. При первой установке Electron скачивает бинарник для текущей платформы.

## Работа с кодом

- `src/main/` управляет окном Electron и системными API.
- `src/features/<фича>/` содержит всё для одной возможности: типы, чистые функции с тестами, модель Reatom, адаптеры и компоненты. Роль файла задаёт суффикс: `.domain.ts`, `.model.ts`, `.adapter.ts`, `.tsx` и другие.
- `src/renderer/main.tsx` подключает браузерные адаптеры, создаёт модели и монтирует интерфейс.
- `npm test` запускает vitest для чистых функций.
- `npm run check` проверяет типы, запускает Oxlint с информацией о типах, тесты и сверяет диагностики на примерах. Эта же команда выполняется перед сборкой.

Роли файлов, допустимые импорты, путь сообщения от формы до хранилища и порядок планирования изменений описаны в [архитектуре приложения](docs/architecture.md).

Соглашения, примеры и порядок добавления правил собраны в [docs-lint](docs-lint/README.md).
